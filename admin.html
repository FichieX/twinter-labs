Sign in

Posts are saved straight into the website's GitHub repository, so you sign in with a GitHub access token instead of a password.

How do I get a token? (one-time setup, 2 minutes)
  1. Open GitHub → New fine-grained token while logged in as the repository owner.
  2. Give it a name such as Twinter Labs admin and pick an expiration date.
  3. Under Repository access choose Only select repositories → twinter-labs.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Press Generate token, copy it, and paste it above.

The token stays in this browser only. Anyone who has it can change the website, so treat it like a password.

Send orders to our Gmail

One-time setup in the Google account that should receive the orders. After it, every order from the home page form is emailed to you and saved as a row in a Google Sheet.

  1. Signed in to that Google account, create a new Google Sheet (type sheets.new in the address bar) and name it, for example, Twinter Labs orders.
  2. In the sheet menu choose Extensions → Apps Script. Delete the code that is there, then paste the script below.
  3. Check the email address on the line starting with NOTIFY_EMAIL, then press the save icon.
  4. Press Deploy → New deployment, choose type Web app, set Execute as: Me and Who has access: Anyone, and press Deploy.
  5. Google asks for permission the first time: press Authorize access, pick the account, then Advanced → Go to … (unsafe) → Allow. This warning appears because the script is your own and not reviewed by Google.
  6. Copy the Web app URL (it ends in /exec) and paste it in the first box below. Copy the sheet's address from the browser into the second box, then press Save.
