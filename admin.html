Sign in

Posts are saved straight into the website's GitHub repository, so you sign in with a GitHub access token instead of a password.

How do I get a token? (one-time setup, 2 minutes)
  1. Open GitHub → New fine-grained token while logged in as the repository owner.
  2. Give it a name such as Twinter Labs admin and pick an expiration date.
  3. Under Repository access choose Only select repositories → twinter-labs.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Press Generate token, copy it, and paste it above.

The token stays in this browser only. Anyone who has it can change the website, so treat it like a password.
